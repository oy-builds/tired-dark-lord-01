# The Tired Dark Lord

A ~100-word villain monologue for a fantasy lich, Malachar the Undying, whose undead legions cannot rise until the Death Ministry stamps form 44-B — and the clerk who stamps it died before he did. The exhaustion lives in the pauses, the deflections and the mop bucket, never in a plain statement of weariness. Running `main.ts` writes the monologue to `/output/entry.txt`.
